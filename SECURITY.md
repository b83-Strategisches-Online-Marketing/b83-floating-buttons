# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils aktuelle Version. Bitte immer die neueste Version verwenden (Updates im WordPress-Backend).

## Sicherheitslücke melden

Bitte **keine öffentlichen Issues** für Sicherheitslücken anlegen.

- Per E-Mail an office@b83.at

Hilfreich sind eine kurze Beschreibung, betroffene Version und Schritte zum Nachstellen. Wir melden uns in der Regel innerhalb von 5 Werktagen und informieren über die Behebung.

---

# Security Policy (English)

Please do not open public issues for security vulnerabilities. Report them privately by email to office@b83.at.
