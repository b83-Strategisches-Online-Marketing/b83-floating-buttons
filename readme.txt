Floating contact buttons on any edge of the screen: phone, email, WhatsApp, chat or links, with icons that expand into text on hover.

== Description ==

b83 Floating Buttons adds a bar of buttons to the left, right, top or bottom edge of every page. Each button shows an icon and slides out with a heading and a small line of text when visitors hover over it. A tooltip can add details such as office hours.

You build the bars in a visual editor with a live preview for desktop, tablet and mobile. It works with any theme and page builder, including Elementor and the block editor, and loads no icon font.

= Features =

* Several bars, each on its own screen edge and with its own alignment
* More than 2,100 Font Awesome Free icons with search, 76 built-in icons including WhatsApp, Instagram and Booking.com, or your own image from the media library, all embedded as small SVGs
* Actions: link, phone call, email with subject, WhatsApp with prefilled message, chat and messenger links (Messenger, Telegram, Signal, Skype, Viber, Teams), text message, back to top, or info only
* Heading and small text when expanded, tooltip, optional new window and nofollow
* Colours for normal and hover state per bar, own colours per button, size, corner radius, shadow, font size and weight
* Mobile: show or hide per device, keep the desktop behaviour, show icons only, or turn the bar into a full-width bar at the bottom
* Exclude pages, export and import bars between websites
* Accessible: keyboard navigation, screen reader texts, respects reduced motion
* Clears the page cache after saving (WP Rocket, LiteSpeed Cache, W3 Total Cache, WP Super Cache, SiteGround)
* Translated into German

= Pro =

Floating Buttons Pro shows a phone or WhatsApp button only during your opening hours, with up to three time ranges per day. The check runs in the browser, so it stays correct with page caching. Display rules limit a bar to chosen pages, content types or languages (WPML and Polylang), and every click can be sent as an event to Google Analytics 4 or Google Tag Manager. You can try Pro for 30 days without entering payment details.

== Installation ==

1. Install the plugin from Plugins → Add New, or upload the ZIP file.
2. Activate it and open b83 → Floating Buttons.
3. Click "New bar", add your buttons and save.

== Frequently Asked Questions ==

= Does the plugin load Font Awesome? =

No. The icon you choose is stored as a small SVG with the button. No font and no extra stylesheet from Font Awesome is loaded on your pages.

= How do the buttons behave on phones? =

You choose per bar: like on desktop (first tap expands, second tap opens), icons only (a tap opens right away), or a full-width bar at the bottom of the screen.

= Can I style the buttons with my own CSS? =

Yes. All elements have fixed CSS classes starting with `b83-fb`, and the design values are CSS variables starting with `--b83fb-`.

= Does click tracking set cookies? =

No. The plugin only passes the event to Google Tag Manager or Google Analytics if they are already on the page. Whether they record anything is still decided by your cookie banner.
